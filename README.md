# Nutregam - Sistema de Gestión

Sistema centralizado para la gestión de producción, ventas, inventario y control de maquinaria.

## Tecnologías Utilizadas

### Frontend
- **React 18** - Librería de interfaz de usuario
- **TypeScript** - Superset tipado de JavaScript
- **Vite** - Build tool y servidor de desarrollo
- **Tailwind CSS** - Framework de estilos utility-first

### UI Components
- **shadcn/ui** - Componentes de interfaz reutilizables
- **Radix UI** - Primitivas de UI accesibles
- **Lucide React** - Iconos
- **Recharts** - Visualización de datos y gráficos

### Gestión de Estado y Datos
- **React Context API** - Gestión de estado global
- **Custom Hooks** - Lógica de negocio reutilizable

### Utilidades
- **date-fns** - Manipulación de fechas
- **Sonner** - Notificaciones toast
- **React Hook Form** - Gestión de formularios
- **Zod** - Validación de esquemas

### Backend
- **Azure Functions** - Serverless backend
- **Azure SQL Database** - Base de datos relacional

### Desarrollo
- **ESLint** - Linter de código
- **PostCSS** - Procesador de CSS
